# 2027 Grand Prize target qualifier — 2026-09-30

Frozen output from the first ScrollQ Grand Prize qualification pass.

Reproduce from the repository root:

```bash
scrollq-grand-prize \
  --volumes artifacts/2026-09-30-scrollq/volumes.json \
  --out /tmp/grand-prize-targets.json
```

Method: a weight-free Pareto frontier over the existing ScrollQ scan-quality
score and current public segment count. Surface and lasagna predictions are
required bootstrap assets. This is campaign triage, not a readability or ink
prediction.

Current frontier: **PHerc0813**, **PHerc1447**.

Source metadata is dated 2026-09-30 and each target row contains its official
Scroll Prize data-browser URL. PHerc1203's 2.403 µm same-scroll scan is
explicitly recorded as excluded from the prize-volume comparison.

# Topology-conditioned uncertainty audit — synthetic controls (2026-10-07)

**Synthetic only. No real checkpoint, scroll or prediction is measured here.**
The panel is generated by `_synthetic_units()` in
`src/scrollq/topology_uncertainty.py`; the numbers describe the control
construction, not detection limits on real papyrus.

- Base commit: `0eb0bd8b8957ed4ce3b7aba2ecf99aca254507b5` (this change adds the
  module on top of it)
- Constants frozen in the module before output was read: seed `20261007`, 300
  replicates, 12 permutation trials, maximum null false-detection rate 0.2.
  One panel defect was fixed after a first run: per-member noise made reference
  fields (members at p=0.5) look more "disagreeing" than confident ones, so
  confident errors scored MI AUROC 1.0. Noise is now shared by all members, so
  agreeing members have exactly zero disagreement. That was a defect of the
  panel, not of the metric.
- `self-test.json` SHA-256:
  `c7c87ebefc38220d367fa542c3c704bf6b4867daf57a409448177bccbc08ca02`

## Reproduce

```bash
scroliq-topology-uncertainty self-test > self-test.json
```

About 5 seconds on one CPU; `tests/test_topology_uncertainty.py` re-runs it.

## What it shows

| check | result |
|---|---|
| planted split-member fault ranked and beats confidence | MI AUROC 1.0 vs confidence 0.0 (the plant inverts confidence) |
| confidently wrong fields with zero disagreement credited | no (MI AUROC exactly 0.5) |
| failure-mask localization | detected |
| permuted-label false promotion rate | 0 of 12 |
| rule with no gain | `DISMISS` |
| rule with an unmeasured stratum | `UNVERIFIED` |

These show the machinery and rule behave as specified, nothing more. The real
question (CT-supported fixtures on a frozen ensemble) is open; see
[`docs/topology-uncertainty.md`](../../docs/topology-uncertainty.md).

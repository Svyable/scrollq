What the prize actually requiresOfficial rules checked 2026-10-02; the Challenge page remains authoritative.

The 2027 Grand Prize requires a reproducible open-source pipeline, seamless VC3D integration, 100% recto unrolling, column-scale TIFXYZ meshes and images, legible ink, strict train/prediction separation, reproducibility records, false-positive mitigation, and held-out validation. The deadline is June 25, 2027.

Read the official Grand Prize rules →

ScrolIQ's role: make each stage auditable and volume-bound so weak evidence cannot silently become a readiness claim. It does not currently claim a qualifying full-scroll result.

Shortest path from diagnostics to a qualifying package

  1. Choose one exact eligible volume using blind geometry evidence, not a blended “best scroll” score. Keep failed regions in the denominator.
  2. Close the surface chain first: winding → spiral/geometry → TIFXYZ → recto coverage, with exact-volume bindings at every handoff.
  3. Make VC3D the reviewer path, not an export target. The final workflow should open, inspect, and reproduce the same evidence in VC3D with minimal translation.
  4. Only then spend large ink-model compute. Require train/prediction exclusion certificates, fixed seeds, public tracking, and falsification controls before counting any letters.
  5. Automate submission packaging early. Generate sequential column meshes, matching images, 1 cm scale bars, and the full-scroll numbered banner from the same manifest.
  6. Ship the reproduction environment before the result is “perfect.” Docker, system requirements, licenses, exact commands, and human-time accounting should be continuously testable.

Current claim boundary

What this page does not claim: that ScrolIQ predicts readability, that a high scan-health score implies a good surface, that a passing mesh audit proves sheet identity, or that an ink prediction is real because its provenance is clean. Those are separate empirical questions and remain separate on purpose.

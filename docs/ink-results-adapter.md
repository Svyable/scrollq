# Ink results adapter

`scroliq-ink-results` converts one `scroliq-ink-validate` report per held-out
region into the common `models/results.schema.json` contract consumed by
`scroliq-eval`.

This is the bridge between physical ink validation and model ranking. It does
not recompute ink metrics. Instead it verifies that each region report is
eligible to enter the common evaluator and preserves its exact evidence hashes.

## Why this exists

A model-level mean is only trustworthy if hard regions cannot disappear and the
scored prediction belongs to the same checkpoint/inference identity that passed
preflight. Hand-copying AUC values into a spreadsheet loses both properties.

The adapter therefore:

- validates the model card and held-out dataset manifest;
- reuses `scroliq-eval` preflight to verify checkpoint bytes, inference script,
  canonical inference configuration, task declaration, leakage identifiers and
  stochastic seed requirements;
- requires every supplied report to come from `scroliq-ink-validate`;
- requires the report split ID to equal the expected region ID;
- requires `held_out: true`, `training_overlap: none`, known ground truth and
  `prize_evidence_ready: true`;
- requires the ink report checkpoint SHA-256 to match the verified model;
- carries ROC AUC and the other finite ink metrics into the common result row;
- binds the exact ink-validation report, evaluated-array digest, prediction,
  labels and validation-mask hashes when present;
- emits an explicit failed row for every expected region whose report is
  missing or invalid.

A missing or failed region therefore remains in the denominator when the output
is passed to `scroliq-eval`.

## Example

A held-out dataset may declare three PHerc1447 windings and ROC AUC as its
primary metric:

```json
{
  "schema_version": 1,
  "id": "pherc1447-v8in-zero-shot",
  "task": "ink",
  "held_out": true,
  "evaluation_data": ["pherc1447-refined-labels-v1"],
  "regions": [
    {"id": "w058"},
    {"id": "w060"},
    {"id": "w062"}
  ],
  "primary_metric": {
    "name": "roc_auc",
    "higher_is_better": true,
    "failure_value": 0.0
  },
  "visibility": "public",
  "bootstrap_seed": 1447
}
```

After running `scroliq-ink-validate` independently for every winding:

```bash
scroliq-ink-results \
  --model models/v8in/model.json \
  --dataset eval/pherc1447-zero-shot.json \
  --checkpoint release/model.pt \
  --root . \
  --region w058=out/w058.ink-validation.json \
  --region w060=out/w060.ink-validation.json \
  --region w062=out/w062.ink-validation.json \
  --out out/v8in.pherc1447.regions.json
```

Then aggregate without changing any region score:

```bash
scroliq-eval \
  --model models/v8in/model.json \
  --dataset eval/pherc1447-zero-shot.json \
  --checkpoint release/model.pt \
  --results out/v8in.pherc1447.regions.json \
  --root . \
  --out out/v8in.pherc1447.eval.json
```

`scroliq-eval` verifies that the checkpoint/script/config identities copied by
the adapter exactly match its own independent preflight before making the result
rank-eligible.

## Failure semantics

The adapter itself exits zero only when every expected region has a valid
prize-ready ink report. It still writes a region-results file when one or more
regions fail, so the common evaluator can assign its preregistered failure value
instead of dropping those regions.

Unknown region IDs and a blocked model preflight are contract errors and do not
produce a misleading partial evaluation.

## Limits

This binds the exact prediction bytes reported by `scroliq-ink-validate` and
the exact verified checkpoint/script/config identity. It does **not** by itself
prove that an arbitrary prediction file was generated by that executable run.
Submission-grade campaigns should additionally retain the inference runner
receipt/container log that binds generated prediction artifacts to the run.

ROC AUC and related ink metrics measure ink-signal discrimination. They are not
papyrological legibility measurements.
